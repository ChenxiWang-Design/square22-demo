# B1chat 预览服务器问题解决记录

## 问题描述

**错误现象：**
- 浏览器访问 `http://localhost:8080/B1chat/index.html` 时出现错误
- 错误代码：`ERR_CONNECTION_REFUSED`
- 提示信息："localhost 拒绝了我们的连接请求"

**问题原因：**
预览服务器未启动或启动失败，导致端口 8080 没有服务在监听。

## 解决方案

### 方法一：使用批处理文件启动（推荐）

1. 双击运行 `启动预览服务器.bat`
2. 等待服务器启动完成
3. 访问 `http://localhost:8080/B1chat/index.html`

### 方法二：手动启动服务器

1. 打开 PowerShell 或命令提示符
2. 切换到 B1chat 目录：
   ```powershell
   cd "c:\Users\24251\.cursor\Square22\B1chat"
   ```
3. 检查依赖是否安装：
   ```powershell
   Test-Path "..\node_modules\express"
   ```
   如果返回 `False`，需要先安装依赖：
   ```powershell
   cd ..
   npm install express
   cd B1chat
   ```
4. 启动服务器：
   ```powershell
   node preview-server.js
   ```
5. 看到启动成功信息后，访问 `http://localhost:8080/B1chat/index.html`

### 方法三：检查并重启服务器

如果服务器已启动但无法访问，按以下步骤排查：

1. **检查端口占用情况：**
   ```powershell
   netstat -ano | findstr :8080
   ```
   - 如果有输出，说明端口被占用（可能是之前的服务器进程）
   - 如果没有输出，说明服务器未启动

2. **如果端口被占用但无法访问：**
   - 找到占用端口的进程ID（PID）
   - 结束该进程：
     ```powershell
     taskkill /PID <进程ID> /F
     ```
   - 重新启动服务器

3. **如果端口未被占用：**
   - 按照方法二重新启动服务器

## 验证服务器是否正常运行

启动服务器后，运行以下命令验证：
```powershell
netstat -ano | findstr :8080
```

如果看到类似以下输出，说明服务器正常运行：
```
TCP    0.0.0.0:8080           0.0.0.0:0              LISTENING       <PID>
```

## 常见问题

### Q: 为什么服务器总是停止？
A: 如果是在命令提示符中直接运行 `node preview-server.js`，关闭窗口会停止服务器。建议：
- 使用批处理文件启动（方法一）
- 或者在后台运行服务器

### Q: 端口 8080 被占用怎么办？
A: 可以修改 `preview-server.js` 中的 `PORT` 变量，改为其他端口（如 3000、8081 等），然后更新访问地址。

### Q: 依赖安装失败怎么办？
A: 确保已安装 Node.js，然后在项目根目录运行：
```powershell
npm install express
```
