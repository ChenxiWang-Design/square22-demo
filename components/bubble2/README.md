# Bubble2 组件

黄块 + 黄气泡（狼人杀风格），长按默认态 → 展开态（蓝黑渐变卡片 + 狼人杀对话 + 可滚动聊天）。样式与 `bubble2.pen` 对应。

## 所需文件（嵌入主界面时请一并部署）

| 文件 | 说明 |
|------|------|
| `index.html` | 组件页，可单独打开或通过主界面 iframe 嵌入 |
| `bubble2.css` | 默认态 / 展开态 / 聊天区 / 嵌入布局 |
| `bubble2.js` | 长按检测、展开/收起、遮罩关闭 |

依赖主界面或项目根目录的图片（若单独部署需一并拷贝）：

- `images/Group 27.png`、`images/Group 24.png`、`images/Group 28.png`（默认态素材）

## 嵌入主界面

主界面通过 iframe 引入组件并加 `?embed=1`，气泡会使用嵌入布局（默认与 bubble1 相同为左下区域，可在主界面 CSS 中为不同 iframe 设不同定位）：

```html
<iframe src="components/bubble2/index.html?embed=1" title="Bubble2"></iframe>
```

组件内 `body` 背景为透明，便于叠在主界面背景上。

## 本地预览

- **单独预览**：用浏览器打开 `components/bubble2/index.html`。
- **主界面预览**：在项目根目录打开根目录的 `index.html`，并在其中加入上述 iframe（可为 bubble2 单独设定位避免与 bubble1 重叠）。

建议使用本地静态服务（如 `npx serve .`）再访问，避免 `file://` 限制。

## 交互说明

- **长按**默认态（约 0.5 秒）→ 展开态浮层（蓝黑渐变卡片 + 狼人杀对话）。
- **点击**灰色遮罩 → 收起展开态。
- 展开态内聊天区域可**右侧滚动条**上下滑动查看。

## 样式与 Pencil 对应

- **默认态**：上方黄矩形 150×110（两图横排，边距 6），下方黄气泡 118×41（一图），与 bubble2.pen「Bubble2-默认态」一致。
- **展开态**：223×274，蓝黑渐变、黄描边、内为微信式狼人杀对话与系统消息，与「Bubble2-展开态」一致。
