# Bubble5 组件

电影票风格气泡：默认态为票券预览，长按默认态 → 展开态（出票口 + 票从口内拉出，底层灰色矩形固定）。嵌入主界面时与其它气泡一致：长按展开，主界面底部产生模糊遮罩。

## 所需文件（嵌入主界面时请一并部署）

| 文件 | 说明 |
|------|------|
| `index.html` | 组件页，可单独打开或通过主界面 iframe 嵌入 |
| `bubble5.css` | 默认态 / 展开态 / 出票口 / 票拉出动效 / 嵌入布局 |
| `bubble5.js` | 长按检测、展开/收起、票拉出、视频播放、postMessage |

依赖主界面或项目根目录的素材（若单独部署需一并拷贝）：

- `Pic/bubble5/ticket1.png`（默认态票券图）
- `Pic/bubble5/ticket2.png`（展开态票券图）
- `Pic/bubble5/video.mp4`（展开态灰色矩形内视频）

## 嵌入主界面

主界面通过 iframe 引入组件并加 `?embed=1`，气泡使用嵌入布局（默认态 177×174，展开态 248×266）：

```html
<iframe src="components/bubble5/index.html?embed=1" title="Bubble5 组件" scrolling="no"></iframe>
```

- 长按默认态后组件发送 `bubble5-expanded`，主界面显示全屏遮罩（`backdrop-filter: blur(8px)`），组件底部产生模糊。
- 收起时发送 `bubble5-collapsed`；主界面可发 `collapse` 通知组件收起。

## 本地预览

- **单独预览**：用浏览器打开 `components/bubble5/index.html`。
- **主界面预览**：在项目根目录打开根目录的 `index.html`，bubble5 已置入（左下区域，与其它气泡并列）。

建议使用本地静态服务（如 `npx serve .`）再访问，避免 `file://` 与视频/图片限制。

## 交互说明

- **长按**默认态（约 0.5 秒）→ 展开态浮层；票从顶部粉色出票口缓缓拉出，展开态内视频自动播放。
- **点击**灰色遮罩或主界面遮罩 → 收起展开态，视频暂停。
- 嵌入主界面时，展开后主界面全屏遮罩出现，**组件底部（主界面其余区域）产生模糊**，与 bubble1～bubble4 一致。

## 样式与 Pencil 对应

- **默认态**：177×174，气泡形状 path + ticket1 + 文本「菜仔」「正在看电影中...」，与 bubble5.pen「Bubble5-默认态」一致。
- **展开态**：248×266，底层灰色圆角矩形（固定）+ 粉色出票口（含药丸形）+ ticket2 及上方内容（票）从出票口拉出，与「Bubble5-展开态」一致。
